# install suitecrm

## This installs SuiteCRM on crm.redURI
- Lives in `www/vapps/suitecrm`
- On failure, leftovers this install created are removed; pre-existing domain and certs stay

## Usage
- `ink install suitecrm [ -b database ] [ -u dbuser ] [ -p dbpassword ]`
  - Same as `./installsuitecrm`
