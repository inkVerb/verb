# install inkmail

## This installs the Go inkMail control panel on po.emailURI
- Agnostic: talks to `ink mail` which picks inkemail (Maddy) or inkvmail (Postfix)
- Roundcube stays webmail. PFA stays for Postfix if you installed it.
- BIMI: upload lands in `/srv/vip/files/DOMAIN.bimi.svg`, then `ink set bimi -p vip -d DOMAIN`

## Usage
- `ink install inkmail [ -p folder ]`
- Folder under `https://po.emailURI/` is autogenerated if omitted
