# install inkmailadmin

## This installs the Go inkMail control panel on po.emailTLDURI
- Agnostic: talks to `ink mail` which picks inkemail (Maddy) or inkvmail (Postfix)
- Roundcube stays webmail. PFA stays for Postfix if you installed it.
- Binary: `/srv/www/email/inkmail`
- Live config: `/etc/inkmail/conf` (not the verb tree)
- BIMI: upload lands in `/srv/vip/files/DOMAIN.svg`, then `ink set bimi -p vip -d DOMAIN`
- Installs Go with pacman if it is not already on the box
- Change the URL folder later with `ink set inkmailpath -p folder`

## Usage
- `ink install inkmailadmin [ -p folder ]`
- Folder under `https://po.emailTLDURI/` is autogenerated if omitted
