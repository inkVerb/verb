# install orangehrm

## This installs OrangeHRM on hrm.redURI
- Lives in `www/vapps/orangehrm`, linked from the redURI HRM host
- On failure, leftovers this install created are removed; pre-existing domain and certs stay

## Usage
- `ink install orangehrm [ -b database ] [ -u dbuser ] [ -p dbpassword ]`
  - Same as `./installorangehrm`
